**LESSONS FROM LECTURE 1**

**----------------------**



**Data mining** is defined as the computational process of extracting patterns and knowledge from massive datasets, forming the core component of the broader **Knowledge Discovery in Databases (KDD)** workflow which includes data cleaning, integration, selection, transformation, pattern evaluation, and knowledge presentation. It's multi-disciplinary foundations integrate **statistics, machine learning, database-oriented techniques, and data visualization**. Also, analyzing this data requires a clear understanding of various data types and attributes, which are broadly divided into qualitative categorical features such as **nominal, binary, and ordinal attributes—and quantitative numeric attributes** like **interval-scaled and ratio-scaled data, alongside discrete and continuous variables**. To ensure high analytical efficiency and accuracy, raw data must undergo preprocessing and transformation stages, including noise elimination, integration, normalization, discretization, compression, sampling, and dimensionality reduction.



To assess similarity or likeness of data objects if they can be used in  classification or clustering, various  data structures and distance metrics are used. Numeric data distance can be computed using **Euclidean, Manhattan, Minkowski, and Supremum (*Lmax*) distances**, while specialized measures like **Cosine similarity, the Tanimoto coefficient, and Kullback-Leibler (KL) divergence** handle text analysis, vector comparisons, and probability distribution differences. Finally, real-world databases often contain mixed attribute types, which are effectively processed together by normalizing individual contributions into a unified dissimilarity scale ranging from 0.0 to 1.0.
